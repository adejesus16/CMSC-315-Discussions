# Unit 8 Discussion: Breadth-First Search (BFS)

## Overview

This assignment explores graph traversal using Breadth-First Search (BFS).

## Learning Objectives

- Represent graphs using adjacency lists
- Implement BFS
- Use queues in graph traversal
- Analyze graph traversal behavior

## Requirements

1. Create a graph.
2. Perform BFS traversal.
3. Add nodes or edges.
4. Demonstrate edge cases.
5. Analyze BFS behavior.
6. Create a real-world graph example.

While completing this assignment, I learned how graphs could be represented with adjacency lists and how Breadth-First Search could be used to move through connected nodes. I also learned how a queue helped BFS process nodes in the order they were discovered. Using a visited set prevented the program from repeatedly visiting the same nodes.

One challenge I encountered was understanding how the queue and visited set worked together. Breaking the traversal into smaller steps and looking at the order of the campus buildings helped me understand the process. I also tested edge cases, including a missing starting node and a graph with only one node, to make sure the program handled unusual situations correctly.

BFS and DFS both traverse graphs, but they use different approaches. BFS explores nearby nodes level by level, while DFS follows one path as deeply as possible before returning to explore another path. BFS could be useful for finding short routes in a campus or social network. DFS could be useful for exploring file systems or determining whether a path exists through a larger structure.
